## Net Worth Asset & Liability Snapshot Tracker

Tracks personal assets (cash, stocks, real estate, other) and liabilities (mortgage, auto, credit, other) to compute net worth in real time. Displays a donut pie chart of asset category breakdown with percentages, running totals for assets and liabilities, and a net worth banner. All data persists in localStorage. Supports text export as a downloadable summary file.

**Tech:** Vanilla JS, HTML Canvas, localStorage, Tailwind CSS CDN.  
**Usage:** Add asset/liability rows with name, category, and value. Net worth and chart update immediately. Click Export to download a plain-text summary.
